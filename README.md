**Инструкция по запуску проекта**

1. Установите [.NET 8](https://dotnet.microsoft.com/download/dotnet/8.0).
2. Перейдите в папку с проектом и выполните команду:
   - `dotnet build` — для сборки проекта,
   - `dotnet run` — для запуска.
3. Откройте браузер и перейдите по адресу: [http://localhost:5080](http://localhost:5080).
4. Введите свой никнейм и нажмите **Готово**.

---

**Требования для работы сайта**

Для корректной работы проекта необходимо:
- Установить приложение [Ollama](https://ollama.ai/).
- Скачать и установить модель Ollama (например, с сайта [Hugging Face](https://huggingface.co/)).
- Перезапустить программу — установленные модели автоматически появятся в списке доступных.

---
**Важно!**
Модели потребляют ресурсы вашего компьютера и могут замедлять его работу. Не рекомендуется устанавливать слишком тяжелые модели, если ваш ПК недостаточно мощный. Ответственность за выбор модели и её влияние на производительность лежит на пользователе.
